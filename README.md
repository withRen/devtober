# Devtober 2026

> **1 mot par jour pendant tout octobre, 1 création en code.**

Comme l'Inktober, mais pour les devs. Chaque jour, un mot sert d'inspiration pour coder quelque chose : un jeu, une animation, de l'art génératif, un outil, une expérience UI… La forme est totalement libre.

- ⏱️ Environ 1h30 à 2h par jour
- 🚀 Pas besoin que ce soit parfait, l'important c'est de publier
- 🏷️ Hashtag : **#devtober**

## Organisation

Un dossier par jour, nommé `day-XX-mot`, qui contient :

- `index.html` : la création, à ouvrir dans un navigateur ;
- `README.md` : ce que fait le code et son lien avec le mot.

```
devtober/
├── README.md
├── index.html          ← la grille des 31 jours
├── day-01-pulse/
│   ├── index.html
│   └── README.md
└── ...
```

## Lancer en local

Aucune installation n'est nécessaire : ouvre `index.html` dans ton navigateur.
