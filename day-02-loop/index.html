Loopjour 02 · générateur de fonds d'écran

Dessine une boucle d'un seul trait, relâche pour valider. Échap pour annuler.

Dépose l'image pour en faire le fond

Styles

Paramètres

Raccourcis clavier

Clique sur un raccourci puis appuie sur la nouvelle touche, avec Maj, Alt ou Ctrl si tu veux. Échap annule, Retour arrière retire le raccourci.

Rendu

Le navigateur demande la carte dédiée. Si c'est la puce intégrée qui s'affiche, c'est le système qui choisit : sous Windows, Paramètres, Affichage, Graphiques, puis « Hautes performances » pour le navigateur.
